Exporters & Log Ingest

How LinkedEye checks exporters and how to send logs to the Logs & Events pages.

Exporter health checks

  • Every minute LinkedEye fetches the metrics URL of each enabled exporter and counts the metric samples in the response.
  • Active: HTTP 2xx with at least one sample. Error: connection, TLS or DNS failure, a non-2xx status, or no samples. Not Configured: no metrics URL. Inactive: disabled.
  • Moving between Active and Error raises an event (source observe, fingerprint exporter:<id>) that appears under Events and is sent to the configured notification channels.
  • Scrapes follow the probe safety policy: private and loopback addresses must be listed in LINKEDEYE_PROBE_ALLOWED_PRIVATE_CIDRS; link-local and cloud metadata addresses are always refused.
  • Log lines are attributed to an exporter when their source equals the exporter name.

Endpoint
POST {{ ingest_url }}
Authentication
Authorization: Bearer <LINKEDEYE_LOG_INGEST_TOKEN>
Body
A JSON array, or NDJSON (one object per line, Content-Type: application/x-ndjson)
Limits
{{ max_entries }} entries and {{ max_kb }} KB per request
Retention
{{ retention_days }} days (LOG_RETENTION_DAYS)
Fields
source, level (DEBUG, INFO, WARN, ERROR, CRITICAL) and message are required; ts (ISO 8601 or Unix time), host, site and attributes (object) are optional.
Events
ERROR and CRITICAL lines raise an event when the same source and message pattern has not been seen in the last 10 minutes.
curl -X POST {{ ingest_url }} \
  -H "Authorization: Bearer $LINKEDEYE_LOG_INGEST_TOKEN" \
  -H "Content-Type: application/json" \
  -d '[{"source":"node-exporter-01","level":"WARN","message":"CPU usage 91%","host":"srv-app-01","site":"Mumbai DC"}]'

Response: {"accepted": 1, "rejected": 0, "errors": [], "events": 0, "events_suppressed": 0}. 401 for a wrong token, 413 when a limit is exceeded, 503 when ingest is disabled.

Shipping logs

Any agent that can POST JSON over HTTP works, for example Vector (http sink with encoding.codec = "json"), Fluent Bit (http output, Format json) or a cron script. Map the agent's fields to source, level and message; put extra fields into attributes.
