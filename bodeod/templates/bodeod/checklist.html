How items are validated

  • URL check – the URL Checker check with this name: Online → {% code "ok" %}, Degraded → {% code "warning" %}, Down → {% code "critical" %}.
  • TCP check – the Telnet / TCP check with this name, mapped the same way.
  • Domain – the Domain Monitor hostname: up → OK, SSL expiring → WARN, down / DNS failed / SSL expired → CRIT.
  • Manual – starts {% code "pending" %} and needs an operator sign-off with a note.
  • A missing or never-checked reference is {% code "unknown" %}. The run fails when a critical item is critical and warns on any warning, unknown or pending item.
